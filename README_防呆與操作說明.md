# Filter Forge：物品群組、樣式階級與防呆說明

## 1. 最重要的規則

Path of Exile Filter 由上往下判斷，物品命中第一條規則後就不再往下找。

- 高數量門檻必須排在低數量門檻之前，例如 `StackSize >= 20`、`StackSize >= 10`、一般數量。
- 高價物品從原群組移出後，新的高價群組應放在原群組之前。
- 最後一條必須是無條件 `Show` 防呆層，用來接住未分類、新增或編輯時遺漏的物品。

編輯器會自動維持上述順序。

## 2. 物品群組

選取含有 `BaseType` 的規則後，右側會出現「物品群組」。

### 拆成新群組

1. 點「拆分／移動物品」。
2. 勾選要獨立的物品，例如「凡人的無知」。
3. 點「拆成新群組」。
4. 新群組會複製原本的 Class、其他條件、顏色、音效、光柱與小地圖圖示。
5. 回到右側修改新群組的樣式。

### 移到其他群組

編輯器只會顯示下列條件都相容的目標，避免移動後永遠無法命中：

- Show／Hide 相同
- Class 相同
- 除 BaseType 外的判斷條件相同
- StackSize 條件相同

勾選物品並選擇目標後，物品會從原群組移除，並使用目標群組的樣式。原群組沒有剩餘物品時會自動刪除。

## 3. 通貨依掉落數量分色

選取沒有 `StackSize` 條件的通貨群組，點「依掉落數量分色」。

可建立多個門檻並分別設定文字、背景與邊框色。例如：

| 順序 | 條件 | 顯示建議 |
|---|---|---|
| 1 | `StackSize >= 20` | 最醒目 |
| 2 | `StackSize >= 10` | 次醒目 |
| 3 | 無 StackSize | 原本普通色 |

編輯器會自動由大到小排序。相同門檻已存在時會更新該條規則，避免重複新增。

## 4. 八階樣式打樣

工具列「樣式階級」提供八個預設：

| 階級 | 用途 |
|---|---|
| T1 神話 | 最稀有／最高價 |
| T2 極高價 | 必撿高價 |
| T3 高價 | 高價主力 |
| T4 中高價 | 值得特別提示 |
| T5 中價 | 穩定有價 |
| T6 常用 | 常撿實用 |
| T7 低價 | 視需求撿取 |
| T8 極低價 | 弱化顯示 |

使用方法：

1. 選擇階級。
2. 搜尋並勾選要加入的物品。
3. 點「套用到勾選物品」。

物品會從原本的 BaseType 群組抽出，再依相容條件組成新規則並套用同一外觀。既有 StackSize 數量分色規則會保留。

若要自訂「高價」樣式：

1. 先在主畫面選一個區塊，調好顏色、字級、光柱與小地圖圖示。
2. 開啟「樣式階級」並選擇 T3 高價。
3. 點「用目前區塊覆蓋此階樣式」。

自訂樣式會保存在目前瀏覽器，之後可重複使用。

## 5. 未分類物品防呆層

有效的防呆層必須同時符合：

- 是無條件 `Show`
- 位於整份 Filter 的最後
- 有特殊顏色
- 有光柱、小地圖圖示或提示音

工具列顯示「防呆 ✓」代表通過；「防呆 !」代表缺少或位置錯誤。

匯出時若防呆層不完整，編輯器會自動補上或修復。Filter Forge 預設防呆樣式為：

- 白色文字
- 紫紅色背景與邊框
- 45 字級
- 粉紅光柱
- 粉紅星形小地圖圖示
- 內建提示音

遊戲中看到這個樣式，代表該物品沒有命中前方分類。請回到編輯器把它加入正確的物品群組或樣式階級。

自行開啟的 Filter 若已經有位於最後、帶特殊色與提示的無條件 `Show`，編輯器會辨識並保留，不會重複再加一條。

## 6. 防呆限制

Filter 可以使用 Class、Rarity、AreaLevel、ItemLevel 等組合條件，因此單看 BaseType 清單無法百分之百靜態證明每個物品一定會命中。最後的無條件 Show 是遊戲執行時最可靠的兜底。

每次大量調整後仍建議：

1. 按工具列「檢查」。
2. 確認「防呆 ✓」。
3. 匯出新檔，不要覆蓋唯一的原始 Filter。
4. 在遊戲內重新載入 Filter，先於安全區域測試提示音與樣式。

所有拆分、移動、數量分色、樣式階級與防呆修復都支援「復原」。

## 7. 首頁「新建 Filter」

「Filter Forge 完整新建」由編輯器內建的 4,624 個不重複物品名稱即時產生，不會直接套用任何第三方 Filter 的規則或樣式。

初始內容包含：

- 通貨、精髓與化石
- 輿圖
- 輿圖碎片與聖甲蟲
- 聯盟與特殊物品
- 命運卡
- 技能與輔助寶石
- 傳奇與裝備底材
- 其他已知物品
- 廣義的傳奇、輿圖、稀有與普通裝備防漏規則
- 最後的未分類物品防呆層

新建時的階級只是安全打樣，不代表當季價格。建立後請使用「樣式階級」勾選物品，依目前聯盟價格重新分配。
