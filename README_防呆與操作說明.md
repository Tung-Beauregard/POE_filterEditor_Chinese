# POE 過濾器編輯器：物品群組、樣式階級與防呆說明

把這個 .md 檔和 `index.html` 放在同一個資料夾，工具列的「說明」按鈕才點得開。

## 0. 版本與更新

左上角標題旁會顯示目前版本，例如 `POE1 · v1.0.0`。滑鼠移上去可以看到版本號與建置日期。

**自動偵測**：頁面開啟 8 秒後、之後每 30 分鐘、以及每次切回這個分頁時，會重新抓取頁面檢查版本。發現新版時底部會跳出提示列，按「立即更新」重新整理即可。如果當下有還沒匯出的修改，會先確認再重整。

**手動檢查**：點一下版本晶片就會立即檢查。

以 `file://` 直接開啟本機檔案時無法檢查更新（瀏覽器安全限制），這種情況會靜靜略過，手動點才會告知。

**給維護者**：改版時只要修改 `index.html` 最前面的兩個常數：

```js
const APP_VERSION='1.0.0';
const APP_BUILD='2026-08-18';
```

偵測是抓取線上的 `index.html` 再用正規式讀出 `APP_VERSION` 來比對，所以這兩行必須留在整份程式的最前面。新建 Filter 產生的檔案，檔頭也會標上產生時的版本號。

## 1. 最重要的規則

Path of Exile Filter 由上往下判斷，物品命中第一條規則後就不再往下找。

- 高數量門檻必須排在低數量門檻之前，例如 `StackSize >= 20`、`StackSize >= 10`、一般數量。
- 高價物品從原群組移出後，新的高價群組應放在原群組之前。
- 防呆層必須是無條件 `Show`，而且**前面不能有任何無條件規則**。

第三點常被誤解。很多嚴格 Filter 的最後一條是無條件的 `Hide`，用來把所有沒命中的東西藏掉。這種情況下，就算你在檔尾再加一條無條件 `Show`，它也永遠不會執行，因為那條 `Hide` 已經先把所有物品接走了。編輯器會偵測這種狀況並明講，不會誤報通過。

編輯器會協助維持順序，但**不會在你按匯出時擅自修改檔案**。

## 2. 物品群組

選取含有 `BaseType` 的規則後，右側會出現「物品群組」。

### 拆成新群組

1. 點「拆分／移動物品」。
2. 勾選要獨立的物品，例如「凡人的無知」。
3. 點「拆成新群組」。
4. 新群組會複製原本的 Class、其他條件、顏色、音效、光柱與小地圖圖示。
5. 回到右側修改新群組的樣式。

### 移到其他群組

編輯器只會顯示下列條件都相容的目標，避免移動後永遠無法命中：

- Show／Hide 相同
- Class 相同
- 除 BaseType 外的判斷條件相同
- StackSize 條件相同

勾選物品並選擇目標後，物品會從原群組移除，並使用目標群組的樣式。原群組沒有剩餘物品時會自動刪除。

**順序限制**：如果檔案更前面有一條只靠 `Class` 比對的通用規則，物品仍然會先被那條攔截。這是 Filter 先匹配先贏的本質，工具無法完全避免。大量移動後建議按一次「檢查」。

## 3. 通貨依掉落數量分色

選取沒有 `StackSize` 條件的通貨群組，點「依掉落數量分色」。

可建立多個門檻並分別設定文字、背景與邊框色。例如：

| 順序 | 條件 | 顯示建議 |
|---|---|---|
| 1 | `StackSize >= 20` | 最醒目 |
| 2 | `StackSize >= 10` | 次醒目 |
| 3 | 無 StackSize | 原本普通色 |

編輯器會自動由大到小排序。相同門檻已存在時會更新該條規則，避免重複新增。原本設定過的透明度會保留，不會被色票蓋成不透明。

## 4. 八階樣式打樣

工具列「樣式階級」提供八個預設：

| 階級 | 用途 |
|---|---|
| T1 神話 | 最稀有／最高價 |
| T2 極高價 | 必撿高價 |
| T3 高價 | 高價主力 |
| T4 中高價 | 值得特別提示 |
| T5 中價 | 穩定有價 |
| T6 常用 | 常撿實用 |
| T7 低價 | 視需求撿取 |
| T8 極低價 | 弱化顯示 |

使用方法：

1. 選擇階級。
2. 搜尋並勾選要加入的物品。
3. 點「套用到勾選物品」。

物品會從原本的 BaseType 群組抽出，再依相容條件組成新規則並套用同一外觀。既有 StackSize 數量分色規則會保留。

**注意**：物品清單裡包含目前被 `Hide` 隱藏的物品，這些會標上「目前隱藏」。套用階級會把它們改成顯示，勾選前請確認這是你要的。

若要自訂「高價」樣式：

1. 先在主畫面選一個區塊，調好顏色、字級、光柱與小地圖圖示。
2. 開啟「樣式階級」並選擇 T3 高價。
3. 點「用目前區塊覆蓋此階樣式」。

自訂樣式會保存在目前瀏覽器。以 `file://` 開啟時部分瀏覽器不允許寫入，這時樣式只在本次操作有效。

## 5. 未分類物品防呆層

有效的防呆層必須同時符合：

- 是無條件 `Show`
- 有特殊顏色
- 有光柱、小地圖圖示或提示音
- **前面沒有任何無條件規則攔截它**

工具列顯示「防呆 ✓」代表通過；「防呆 !」代表有問題。點進去會說明是哪一種：

| 狀況 | 編輯器的處理 |
|---|---|
| 找不到兜底 `Show` | 提供「立即修復」，在檔尾新增一條 |
| 有兜底 `Show` 但沒有特殊樣式 | 提供「立即修復」，套上防呆樣式 |
| 前面有無條件規則擋住 | 說明是哪一條、影響幾個區塊，讓你自己決定 |

第三種不會自動處理，因為那多半是原作者刻意的設計。你有兩個選擇：

- **保留現狀**：接受這份 Filter 會靜靜隱藏未命中的物品。
- **把防呆層移到它前面**：未命中的物品改成醒目顯示，但那條規則以及它後面的所有規則都會失效。編輯器會先告訴你會影響幾個區塊。

另外，如果防呆層後面還有其他區塊，那些區塊永遠不會執行，檢查面板會單獨列出來。

編輯器預設防呆樣式：

- 白色文字
- 紫紅色背景與邊框
- 45 字級
- 粉紅光柱
- 粉紅星形小地圖圖示
- 內建提示音

遊戲中看到這個樣式，代表該物品沒有命中前方分類。請回到編輯器把它加入正確的物品群組或樣式階級。

自行開啟的 Filter 若已經有帶特殊色與提示的無條件 `Show`，編輯器會辨識並保留，不會重複再加一條。

## 6. 匯出行為

### 「匯出」與「匯出繁體版」的差別

兩者輸出的**規則完全一樣**，差別只在註解：

| | 匯出 | 匯出繁體版 |
|---|---|---|
| 規則內容（Show/Hide、條件、顏色） | 原樣 | 原樣，完全相同 |
| 註解文字（`#` 後面） | 原樣 | 簡體轉繁體 |
| 引號內的字串（音效路徑等） | 原樣 | 原樣，不轉 |
| 檔名 | `_edited.filter` | `_繁體.filter` |

實測文子那份：5,179 行的註解被轉換，規則程式碼零改動，引號內零改動。

**英文 Filter（例如 NeverSink）兩種匯出的結果完全相同**，因為註解本來就是英文，沒有簡體字可轉。這種情況用哪個都一樣，只有檔名不同。

### 匯出不會改你的檔案

匯出**不會**修改你的 Filter。若防呆層不完整，會先跳出提醒，你可以選擇：

- 取消
- 開啟防呆面板處理
- 仍然匯出

沒有動過的區塊會逐位元組原樣輸出，包含行尾註解、縮排與換行格式。

### 關閉分頁

分頁右側的 ✕ 可以關掉檔案。有未匯出的修改時會先確認，因為關閉後救不回來（復原紀錄也會一起清掉）。關掉最後一個檔案會回到起始畫面。

## 7. 防呆的限制

Filter 可以使用 Class、Rarity、AreaLevel、ItemLevel 等組合條件，因此單看 BaseType 清單無法百分之百靜態證明每個物品一定會命中。最後的無條件 Show 是遊戲執行時最可靠的兜底。

每次大量調整後仍建議：

1. 按工具列「檢查」。
2. 確認「防呆 ✓」。
3. 匯出新檔，不要覆蓋唯一的原始 Filter。
4. 在遊戲內重新載入 Filter，先於安全區域測試提示音與樣式。

所有拆分、移動、數量分色、樣式階級與防呆修復都支援「復原」（Ctrl+Z）。

## 8. 命運卡獎勵

選到含命運卡的區塊時，條件區會列出每張卡的**需要張數**與**獎勵**，例如：

| 卡名 | | 獎勵 |
|---|---|---|
| 藥劑師 | ×5 | 魔血 |
| 瘋醫 | ×8 | 獵首 |
| 明鏡 | ×9 | 卡蘭德的魔鏡 |

只鎖定單張卡的區塊，路徑列會直接顯示「集 N 張 → 獎勵」。獎勵名稱也進了搜尋索引，搜「魔血」就能找到會掉魔血的命運卡區塊。

獎勵資料整理自 PoE Wiki，物品名以台服譯名對應。少數獎勵是「隨機稀有物」「碎裂物品」這種敘述型，沒有單一對應物品，會保留英文原文。張數與獎勵會隨改版微調，以遊戲內為準。

### 傳奇獎勵標記

遊戲裡命運卡的獎勵物品名會依稀有度上色，橘色代表傳奇。編輯器把會給傳奇物品的卡標成橘色並加上「◆傳奇」，例如地牢大師（集 7 → 腰帶，橘色傳奇腰帶）、瘋醫（獵首）、藥劑師（魔血）。

篩選方式：

- 中間搜尋列旁的「◆ 傳奇卡」按鈕，只顯示含傳奇命運卡的區塊。
- 拆分／移動對話框裡的「◆ 只勾傳奇」，一鍵勾選群組內所有傳奇卡。
- 樣式階級對話框搜尋框輸入「傳奇」，只列出傳奇卡。

傳奇標記以可查證的來源（官方 wiki 清單、具名傳奇物品、逐一查證的泛稱卡）為準，目前涵蓋 217 張。少數「換宿命傳奇」的卡可能漏標成普通。如果遇到遊戲裡是橘色、但編輯器標成普通的卡，那是漏網的個案。

首頁的「載入 NeverSink」與工具列的「NeverSink」按鈕，會直接從作者的 GitHub 抓最新版，六個嚴格度都可以選：

| 階級 | 適用 |

| 一般 1-REGULAR | 最寬鬆，撿得多。新開聯盟或剛進遊戲 |

## 10. 首頁「新建 Filter」

「完整新建」由編輯器內建的 **3,164 個可比對底材名稱**即時產生，不會直接套用任何第三方 Filter 的規則或樣式。

### 為什麼不是 4,627 個

內建的譯名庫有 4,627 筆，但其中 1,460 筆**不能拿來寫規則**：

- **傳奇物品名稱（1,240 筆）**：PoE 1 的 `BaseType` 比對的是底材，不是傳奇名稱。`BaseType == "Headhunter"` 永遠不會命中，因為那顆腰帶的底材是 `Leather Belt`。
- **捕獲野獸名稱（220 筆）**：不是地上會掉的物品。

這些名稱仍然用於顯示譯名與分類，只是不會被寫進規則。傳奇物品改由 `Rarity = Unique` 的廣義規則接住。

### 初始內容

- 通貨、精髓與化石
- 輿圖
- 輿圖碎片與聖甲蟲
- 聯盟與特殊物品
- 命運卡
- 技能與輔助寶石
- 裝備底材
- 其他已知物品
- 廣義的傳奇、輿圖、稀有與普通裝備防漏規則
- 最後的未分類物品防呆層

新建時的階級只是安全打樣，不代表當季價格。建立後請使用「樣式階級」勾選物品，依目前聯盟價格重新分配。
